# SIM Guardian - Telegram Edition 🛡️

تطبيق أندرويد مفتوح المصدر لحماية هاتفك عند تغيير الشريحة، يرسل تنبيه فوري على تليجرام بدل SMS (مقبول 100% في Google Play).

### الفكرة
لو تليفونك ضاع وحد حط شريحة تانية، التطبيق يبعتلك على تليجرام:
- تنبيه: تم تغيير الشريحة
- السيريال الجديد
- رابط موقع الجهاز (اختياري)

### المميزات
- بدون صلاحيات SMS الخطيرة
- يعمل بعد إعادة التشغيل
- خفيف ومجاني ومفتوح المصدر

### كيف يعمل؟
1. اعمل بوت من @BotFather وخد الـ Token
2. هات الـ Chat ID من @userinfobot
3. حطهم في التطبيق واضغط تفعيل الحماية

### ⚠️ تنبيه قانوني مهم
هذا التطبيق مخصص لحماية جهازك الشخصي فقط. يمنع استخدامه لتتبع أي شخص بدون موافقته الصريحة. الاستخدام غير القانوني مسؤولية المستخدم وحده.
